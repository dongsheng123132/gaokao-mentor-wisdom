Title: I used Claude Code to generate a bilingual e-book (PDF) from structured JSON data — here's the pipeline Body: I had a side project: curating 105 quotes from a popular Chinese education advisor (Zhang Xuefeng) about college major selection and career planning. The data was already structured as JSON files with categories, tags, and sentiment labels. Instead of manually designing in InDesign or LaTeX, I used Claude Code to build the entire pipeline: 1. Load JSON data → render as semantic HTML with CSS typography 2. Embed QR code images as base64 (self-contained HTML, no external deps) 3. Generate two versions: A4 desktop PDF + mobile-optimized PDF (95mm × 170mm) 4. Playwright handles the HTML → PDF conversion The interesting part was getting CJK (Chinese) text rendering right in Chromium's PDF engine. Learned the hard way that `background-clip: text` with `-webkit-text-fill-color: transparent` silently drops certain CJK characters in PDF output. Switched to solid colors and the issue disappeared. The whole thing is open source: github.com/dongsheng123132/gaokao-mentor-wisdom Happy to answer questions about the CJK PDF rendering gotchas or the Claude Code workflow.
